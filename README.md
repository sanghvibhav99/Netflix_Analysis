# Netflix Analysis

An interactive Netflix dataset analysis dashboard built with Python and Streamlit.

## Features

- Netflix dataset cleaning and preprocessing
- Genre trend analysis over release years
- Top genre analysis by release year
- Genre comparison with rolling averages
- Actor portfolio exploration
- Actor genre distribution
- Filtering by genre, actor, and release year

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
